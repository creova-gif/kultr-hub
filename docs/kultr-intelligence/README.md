- **`VERIFIED`**: Confirmed by direct codebase analysis, executing tests, database schemas, or running endpoints.
- **`DOCUMENTED`**: Stated in project documentation, PRDs, or design briefs, but not independently verified.
- **`PROPOSED`**: Strategic, technical, or commercial recommendation formulated by the founding team.
- **`UNKNOWN`**: Indeterminate from available repository evidence.
